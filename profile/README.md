# Marah

Your games on the TV, played with a controller.

- **[Marah Launcher](https://github.com/MarahHQ/marah-launcher)**: one library for your emulators,
  PC folders and Steam. It runs on Linux, macOS and Windows.
- **[Marah OS](https://github.com/MarahHQ/marah-os)**: a Fedora-based system that starts straight
  into Marah Launcher. Install it from a USB stick.
- **[Packages](https://github.com/MarahHQ/packages)**: the DNF and APT repositories for Marah
  Launcher.

Download and docs: [marahhq.github.io](https://marahhq.github.io).
